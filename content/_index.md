## 这是什么

这是基于斯坦福大学 MATH289 课程的**中文学习笔记网站**。

原课程面向数学系博士生，介绍 AI 如何改变数学研究。本网站以**个人学习笔记**的形式，翻译核心材料、记录学习过程、分享实践代码。

## 你能在这里找到什么

| 分类 | 内容 | 适合谁 |
|------|------|--------|
| 📄 **论文翻译** | Thurston、Etingof、Tao-Klowden 三篇核心论文 | 想读原文但需要中文辅助的人 |

## 推荐阅读路线

### 路线A：数学背景读者（数学系学生/研究者）

```
1. 读 Thurston 论文翻译 → 理解数学的本质是"理解"
2. 读 Etingof 论文翻译 → 理解 AI 时代如何做数学
3. 读学习笔记：两篇对比分析 → 理解两篇论文的关系
4. 读 Lean 入门教程 → 了解形式化工具
5. 读实践资源 → 动手写第一个 Lean 证明
6. 读学习指南：AI 时代数学系新生指南
7. 读核心洞察：理解是数学的不变量
```

### 路线B：AI背景读者（AI算法研究者）

```
1. 读核心洞察：LLM 改变了什么 → 理解背景
2. 读 Tao-Klowden 论文翻译 → 理解数学与AI的哲学关系
3. 读学习笔记：十二原则 → 快速掌握核心原则
4. 读 Lean 入门教程 → 了解形式化工具
5. 读实践资源 → 动手写第一个 Lean 证明
6. 读学习指南：AI 算法研究员的数学学习指南
7. 读核心洞察：数学家在 AI 时代的核心工作
```

### 路线C：快速了解（时间有限）

```
1. 读学习笔记：三篇文献十二原则 → 15分钟掌握核心
2. 读核心洞察：理解是数学的不变量 → 5分钟理解本质
3. 读实践资源：EvenAdd.lean 案例 → 10分钟看一个完整证明
```
