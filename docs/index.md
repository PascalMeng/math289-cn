## 推荐阅读路线

### 路线A：数学背景读者

1. [Thurston 论文翻译](/papers/thurston) → 理解数学的本质是"理解"
2. [Etingof 论文翻译](/papers/etingof) → 理解 AI 时代如何做数学
3. [两篇论文对比分析](/notes/comparison) → 理解两篇论文的关系
4. [Lean 入门教程](/tutorials/lean-basics) → 了解形式化工具
5. [EvenAdd.lean 实践](/practice/) → 动手写第一个证明

1. [LLM 改变了什么](/insights/llm-changes) → 理解背景

3. [三篇文献十二原则](/notes/principles) → 快速掌握核心原则
4. [Lean 入门教程](/tutorials/lean-basics) → 了解形式化工具
5. [AI 算法研究员指南](/guides/researcher) → 如何在工作中学习数学

1. [三篇文献十二原则](/notes/principles) → 15分钟掌握核心
